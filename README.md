### 🔌 DeepSeek Harness 桌面端插件

**[dsh-update-plus](https://github.com/qiqqqqq517/dsh-update-plus)** — 多通道更新检查与一键重启

> 官方 DSH 桌面端没提供的两件事：可选通道的检查更新 + 直接下载官方安装包。
> 稳定 / beta / nightly 三通道、安装包 SHA-512 校验、重启应用与 Host 一并完成。

`JavaScript` `MIT` ｜ [源码](https://github.com/qiqqqqq517/dsh-update-plus)

**[dsh-auto-memory](https://github.com/qiqqqqq517/dsh-auto-memory)** — 主动联想记忆

> 模型开口前先从记忆里主动唤回；会话结束三层自动沉淀；可复用流程固化成技能。
> 交接账本 + PLAN 白板让长任务跨窗口续命；水位感知防记忆无节制膨胀。本地优先、模型无关、零依赖。

`JavaScript` `BSD-3-Clause` ｜ [📦 npm](https://www.npmjs.com/package/@a9i5k4/dsh-auto-memory) ｜ [源码](https://github.com/qiqqqqq517/dsh-auto-memory)
